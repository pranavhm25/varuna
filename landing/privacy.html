Privacy

This page keeps nothing about you.

Last updated 23 November 2026

Varuna is a static page about an academic machine learning project. It sets no cookies, runs no analytics, uses no advertising pixels and does not collect personal information.

What is stored

Nothing. There is no account, no form and no local storage. Your browser may cache the page files so it loads faster on a second visit, as it does for any website.

Typefaces

The Geist and Geist Mono typefaces are included with this page. Rendering the page does not contact a font service.

The live workspace

The button to open the workspace leads to Streamlit Community Cloud, a separate service that hosts the analytical application. That service may keep standard server logs under its own privacy terms. The workspace does not require an account and this page does not pass any information to it.

Links to other sites

The page links to OpenCity Karnataka, GitHub and Streamlit. Those sites have their own privacy practices and are outside the control of this project.

Questions

Open an issue on the project repository for any question about this notice.
